# 图像风格工作台

一张图，挑几种风格，一次出多个版本。本机 Canvas 渲染，不上传图片；首次打开是空态，可直接拖图、粘贴或点「用示例图试试」。P2 增加模板文字、单版参数、原图导出、ZIP 与持久历史。云端 H3 仍是 P3。

## 用法

1. 从左栏打开「图像风格」。
2. 空态可拖入图片、按 `⌘V` 粘贴、点「选择图片」，或点「用示例图试试」。
3. 在左栏挑风格（可多选）；最后点的那个进入画布预览。
4. 参数作用可选「共用」或「当前风格」：当前风格只改这一版的强度/油墨/颗粒。
5. 印刷海报的「模板文字」可展开：海报 / 卡片两种版式，标题、副题、日期、署名。
6. 调输出长边 640/960/1200、画幅（原图/3:2/4:5/3:4），点「生成 N 版」。
7. 试印条里点任意一张切换；「对比原图」打开 A/B 滑杆，可拖动或用方向键。
8. 每张试印卡右上角有「下载」，按原图长边（上限 4096）重新渲染后保存；「打包下载」导出 ZIP + manifest。
9. 右上角「设置」保存 Key、默认尺寸、隐私；Key 存 DSH credentials，P1/P2 不发云端请求。

## P2 范围

- 6 个本机风格：半调网点、双色限墨、Riso 错版、蓝染/氰版、胶片褪色、印刷海报。
- 印刷海报支持 **海报 / 卡片** 两种模板版式（HTML 文字层 + Canvas 图像合成）；卡片建议 3:4。
- 参数支持共用/当前风格；模板文字可改。
- 单张下载按原图长边（≤4096）；「打包下载」生成 `results/*.jpg` + `manifest.json`。
- 历史落 `~/Data/dsh-image-workbench/`（原图 sha256 去重、批次、index），刷新/清缓存后可恢复；Host 不可用时回落 localStorage。
- P3 Host 基础能力（provider/队列/预算/账本）已实现但默认关闭，卡片仍标 P3。

## 已知限制

- 只在 Chromium（DSH Web UI）里验证；HEIC 由浏览器解码能力决定。
- 真实桌面 webview 的下载落盘/多文件策略仍需用户验收。
- 模板文字层用 SVG `foreignObject` 栅格化；DSH 若禁用 data URL SVG，会自动回落 Canvas 版式。
- 本机输出预览 640/960/1200；导出按原图长边（≤4096）；H3 的 1K/2K/4K 是 P3 面积档。
