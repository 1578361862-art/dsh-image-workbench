# 图像风格工作台

一张图，挑几种风格，一次出多个版本。本机 Canvas 渲染，不上传图片；首次打开是空态，可直接拖图、粘贴或点「用示例图试试」。P2 增加模板文字、单版参数、原图导出、ZIP 与持久历史。云端 H3 已接入：保存 Key 后启用（按量 · 国内站），画质 1K/2K/4K 可选。

## 用法

1. 从左栏打开「图像风格」。
2. 空态可拖入图片、按 `⌘V` 粘贴、点「选择图片」，或点「用示例图试试」。
3. 在左栏挑风格（可多选）；最后点的那个进入画布预览。
4. 参数作用可选「共用」或「当前风格」：当前风格只改这一版的强度/油墨/颗粒。
5. 印刷海报的「模板文字」可展开：海报 / 卡片两种版式，标题、副题、日期、署名。
6. 调输出长边 640/960/1200、画幅（原图/3:2/4:5/3:4），点「生成 N 版」。
7. 试印条里点任意一张切换；「对比原图」打开 A/B 滑杆，可拖动或用方向键。
8. 每张试印卡右上角有「下载」，按原图长边（上限 4096）重新渲染后保存；「打包下载」导出 ZIP + manifest。
9. 云端风格：在设置里保存 MiniMax API Key，选中 H3 卡，选云端画质（1K/2K/4K），点生成；首次会确认上传与估价。
10. 右上角「设置」保存 Key、默认尺寸、隐私、预算；Key 存 DSH credentials。

## P4 用法

- **Agent 工具**：在聊天里调用 `image_workbench`，先用 action=estimate 估价，再 action=start + confirm=true 起云端作业，action=status 轮询；只支持云端 H3。
- **批量矩阵**：页面 stage bar 的「批量」，最多 4 图 × 当前本机风格，结果在独立矩阵弹窗里逐张下载或 ZIP；云端请单张。
- **预设风格包**：设置里「导入风格包…」选择一个含 `style.json`（可选 preview 图）的文件夹；目前只支持 `renderer=preset`，base 必须是内置本机风格，params 固定可用字段；不执行脚本/HTML。
- **Context-IR 预览**：选中云端风格后，检查器「预览模型改写」调用 MiniMax Context-IR，显示 revised_prompt/aspect；只消耗增强 token，不出图。

## P5 用法

- 设置「清理 90 天前」删除旧的 batch/原图/job；样式包和账本保留；Host 启动也会自动清理 90 天前数据。
- 云端失败卡（非 unknown）有「重试」；会再次请求并二次确认费用；unknown 不允许一键重试。
- 4K 画质提示：促销 ¥0.2404/张到 2026-11-18，之后 ¥0.4809。

## 区域编辑（蒙版裁剪合成）

- 二次编辑弹窗里用笔刷画蒙版（笔刷大小、擦除、清空、反相）；落盘的是红色叠加 PNG，alpha 通道才是真正的蒙版。
- 有蒙版时：按蒙版 bbox 加 12% 上下文（16–96px，贴边截断、比例收进 1:3–3:1）裁出局部；按裁剪比例请求尺寸；提示词前置「这是从原图裁出的局部区域，只修改该区域内容；不要改变画框外的构图。」，并且只把裁剪图发给 H3 / Seedream。
- 返回结果按蒙版向内羽化（1–12px）合成回原图，再 `POST /composite` 落盘为 `outputs/comp_<id>/region.jpg`（透明来源用 `region.png`）；用返回的本地 URL 作为这一轮结果，最近记录显示「区域编辑」，继续可多轮编辑。
- 没有画蒙版时行为与之前完全一致；Seedream 图层拆分分支忽略蒙版。
- 验收：`plugin/tests/fixtures/region-composite.html` 在真实 Canvas 里复刻裁剪/羽化/合成，断言裁剪框外与蒙版外 0 像素变化；`specs/region-composite.json` 用 dsh_verify 跑（需要先在仓库根起静态服务）。

## P2 范围

- 6 个本机风格：半调网点、双色限墨、Riso 错版、蓝染/氰版、胶片褪色、印刷海报。
- 印刷海报支持 **海报 / 卡片** 两种模板版式（HTML 文字层 + Canvas 图像合成）；卡片建议 3:4。
- 参数支持共用/当前风格；模板文字可改。
- 单张下载按原图长边（≤4096）；「打包下载」生成 `results/*.jpg` + `manifest.json`。
- 历史落 `~/Data/dsh-image-workbench/`（原图 sha256 去重、批次、index），刷新/清缓存后可恢复；Host 不可用时回落 localStorage。
- P3 云端：MiniMax edits provider、队列、预算/账本、1K/2K/4K、partial failure、unknown 不重试；Key 保存后自动启用云端。

## 已知限制

- 只在 Chromium（DSH Web UI）里验证；HEIC 由浏览器解码能力决定。
- 真实桌面 webview 的下载落盘/多文件策略仍需用户验收。
- 模板文字层用 SVG `foreignObject` 栅格化；DSH 若禁用 data URL SVG，会自动回落 Canvas 版式。
- 本机预览 640/960/1200；导出按原图长边（≤4096）；云端画质 1K/2K/4K（2K 编辑约 ¥0.1747/张，4K 促销至 11/18）。
- 区域合成在像素缓冲层面保证蒙版外不变；写回 JPEG 时会重新编码整图，字节仍会变（透明来源走 PNG）。真实 provider 的蒙版区域编辑路径尚未花费真钱跑过，本轮只验证了裁剪/合成与 Host 落盘。
