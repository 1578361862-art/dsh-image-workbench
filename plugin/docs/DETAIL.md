# 图像风格工作台

一张图，挑几种风格，一次出多个版本。P1 只做本机渲染：不联网、不上传图片。首次打开是空态；可以直接拖图、粘贴，或点「用示例图试试」。

## 用法

1. 从左栏打开「图像风格」。
2. 空态可直接拖入图片、按 `⌘V` 粘贴、点「选择图片」，或点「用示例图试试」。
3. 在左栏挑风格（可多选）；最后点的那个进入画布预览。
4. 调强度、颗粒、油墨、输出尺寸和画幅，点「生成 N 版」。
5. 试印条里点任意一张切换；「对比原图」打开 A/B 滑杆，可拖动或用方向键。
6. 每张试印卡右上角有「下载」，直接保存这一张；不再有「下载全部」。
7. 右上角「设置」可保存 MiniMax Key、每日预算、默认尺寸和隐私开关。

## P1 范围

- 六个本机风格：半调网点、双色限墨、Riso 错版、蓝染/氰版、胶片褪色、印刷海报。全部是浏览器 Canvas 渲染。
- 两个云端风格（H3 插画化 / H3 银盐）在货架上标为 P3，暂不可选。
- 最近 3 个批次存在浏览器 `localStorage`，点「最近」里的缩略图可恢复。
- API Key 存在 DSH 的 credentials 记录里（`dsh-image-workbench/minimax`），设置文件只存预算/尺寸/隐私，权限 600，位置 `~/Data/dsh-image-workbench/config.json`。
- 设置里的「试连」只确认 Key 已保存；P1 不发云端请求。

## 已知限制

- 只在 Chromium（DSH Web UI）里验证；HEIC 由浏览器解码能力决定，解不了会提示换图。
- 下载走浏览器 `a[download]`；如果宿主拦截下载，正式版会改为 Host 落盘。
- 本机输出按长边 **640 / 960 / 1200 px**；不做 2K/4K 本机渲染（H3 的 1K/2K/4K 是 P3 的面积档）。
