4

图像分辨率设置

先定画幅，再定像素
1 · ASPECT
先选画幅原图比例 / 1:1 / 4:5 / 3:4 / 16:9 / 9:16；先定构图，避免后裁切切掉主体。
2 · SIZE
再选分辨率1K / 2K / 4K，或固定 W×H；不要同时混用 aspect+area 与固定 size。
3 · LIMITS
模型约束H3 比例约 1:3–3:1；Seedream 约 1:16–16；输出尺寸以 API 返回为准。
