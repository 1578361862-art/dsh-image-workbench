# 固定工作流画布 · 视觉与网页设计检查

检查对象：`plugin/client.js` 的 `#flowCanvas`（0.38.0）。
视觉方向：Coze 式暗色创作台 / 霓虹极光画布；固定五节点，只填内容。

## 视觉

- 全幅暗色画布：深空底 + 四团极光（青/品红/酸绿/琥珀）+ 星点/网格。
- 节点：玻璃卡片、彩色描边、发光端口、入场 stagger。
- 连线：渐变描边 + 流动 dash + glow filter。
- 输出按钮：青→品红→酸绿渐变 + 高光扫过。
- 工具栏：胶囊玻璃，费用/重开/动效/适应/缩放。
- 夜版不依赖宿主主题：画布本身固定暗色，与浅色宿主形成强对比。

## 动态

- 极光 16–24s 漂移、星点 18s、连线 2.4s、端口脉冲。
- 节点 hover 上浮 3px + 彩色 glow。
- 生成按钮 3.2s 高光循环。
- 工具栏「动效」可暂停；`prefers-reduced-motion` 下全部关闭。
- 不使用滚动淡入、视差、随机闪烁。

## 网页设计检查

- 画布 `role="group"`，节点 article aria-label，提示词 aria-label。
- 状态/缩放百分比 `aria-live`，上传/模型 `aria-pressed`。
- 分辨率按钮 `type="button"`；图标按钮有 aria-label。
- 画布无内层滚动；自动 fit 到可用宽高。
- 长提示词/结果/摘要局部 overflow，不撑破节点。
- 提示词输入框按用户偏好不画焦点框；其他控件保留 `:focus-visible`。
- 图片写实际宽高。
- 暗色下 select/textarea/button 使用暗色令牌与原生 dark color-scheme。

## 已知取舍

- 自动 fit 下节点正文为小字号（8–11px），追求一屏完整编排；可点 `+` 放大。
- 画布固定拓扑，不支持拖动/删除/框选。
- 窄屏依赖画布缩放，不做节点重排。
- 极光/星点是装饰层，不承载信息。

## 结果

- 43 Host tests pass；无 pageerror。
- 浅色/暗色宿主下画布均保持同一暗色视觉。
- 本轮未实际调用 H3/Seedream。
