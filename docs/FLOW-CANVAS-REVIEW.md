# 文生图流程处理 · 页面重构记录

参考：`https://share.traecontent.cn/artifact/MNKMTHWMH9C757`
当前实现：0.38.1，`plugin/client.js` 的 `#flowPage`。

## 视觉结构

- 全页浅色流体渐变：蓝 → 紫 → 粉，带缓慢漂浮的模糊光斑。
- 顶部悬浮胶囊 header：
  - 渐变✦图标
  - 标题 + 固定流程副标题
  - 费用 / 重置 / 运行流程
- 主体为纵向白色圆角卡片流：
  - 01 是否上传图片
  - 02 模型选择
  - 03 提示词构建
  - 04 分辨率选择
  - 05 打印机出图
- 卡片之间用虚线连接器 + 小标签说明流程关系。
- 底部深蓝 CONSOLE，显示流程状态。

## 与参考对齐

- 圆角卡片、轻投影、浅灰控件、胶囊按钮。
- 标题左侧数字步骤、右侧说明标签。
- 顶部固定悬浮控制栏。
- 整体是“固定管线 + 参数化选择”，不是可拖拽自由画布。
- 仍保留我们自己的五步：输入 / 模型 / 提示词 / 分辨率 / 输出。

## 交互

- 卡片 hover 上浮 2px。
- 背景光斑缓慢漂移；运行按钮高光扫过。
- `prefers-reduced-motion` 下关闭动画。
- 生成按钮在 header 与输出卡片均可用；两者共享状态。
- 结果仍在输出卡片内查看大图/下载/多轮编辑。

## 无障碍与网页检查

- 页面 `aria-label`；状态 `role=status aria-live`。
- 上传/模型按钮 `aria-pressed`；分辨率 `type=button`。
- 提示词 textarea 有 aria-label；焦点不画焦点框（用户偏好）。
- 所有图片有 alt，结果/源图写实际宽高。
- 暗色主题有独立变量：深色渐变、深色卡片、浅色文字；不发白。
- 页面纵向自然滚动，无内层滚动陷阱。

## 已知取舍

- 采用参考的纵向滚动卡片流，不再是一屏固定节点。
- 未复制参考里的 01A 图片预处理、模型专属参数（seed/watermark/组图）等全部实验控件；保留当前产品已有的输入/模型/提示词/分辨率/输出。
- 未做自由拖拽连线；固定流程才是产品约束。
