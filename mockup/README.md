# 图像风格工作台 · 页面设计稿 v0.2

> **P1 已实现**：插件源码在 [`../plugin/`](../plugin/)，包名 `dsh-image-workbench` 0.1.0；本目录是可交互设计稿，实际页面截图在 [`../shots/`](../shots/)。

可交互的单文件页面，用来先看效果，不是插件本身。

打开 `index.html` 即可（双击；示例图已内嵌，不需要服务器）。

**设计基准：1120 × 860** —— 1440×900 窗口下 DSH 主区的实际大小（左侧栏占 320）。页面 max-width 1120、左右 24px；1020 以下右栏落到下方，760 以下单栏。

## 可以试的

- **左侧风格卡**：点选 / 取消，可多选；最后点的一个成为画布预览
- **强度 / 颗粒 / 油墨**：实时重绘（本机风格约 100–300ms）
- **输出尺寸 1K/2K/4K、画幅 原图/3:2/4:5**：改打印尺寸与预估
- **生成 N 版**：真实 Canvas 出图，试印条逐张出现
- **点试印卡**切换结果；**对比原图** → A/B 滑杆，可拖动
- **右上角「设置」**：打开右侧设置抽屉（生图服务 / 输出预算 / 隐私 / 风格包 / 用量）
- **换一张 / 拖入 / ⌘V 粘贴**：换源图
- **搜索、全部/本机/云端、右上角日夜切换**

## 设置抽屉

- 生图服务：API Key（只显示尾号，可更换）、接口地址（国内站 / 国际站）、模型（H3 标准 / 极速）、计费（按量 / M Plan）、试连一次
- 输出与预算：默认尺寸、每日预算、并发生成 1–4
- 隐私：云端生成前确认费用；本机风格不离开浏览器
- 风格包：已安装数量、导入文件夹、清空历史
- 用量：本月张数与花费、账单入口
- 「保存设置」是抽屉里唯一的实心按钮；Esc、点遮罩、× 都能关

## 哪些是真的

- 本机 6 个风格全部是真实 Canvas 渲染：半调网点、双色限墨、Riso 错版、蓝染/氰版、胶片褪色、印刷海报排版。
- 云端 2 个风格（H3 插画化 / H3 银盐）是**本地模拟**，不调用 MiniMax API；结果卡标「云端 · 演示」。
- 费用与时长按设计文档的价目表写死（2K 编辑 ¥0.17、4K 促销 ¥0.24），不是实时账单。
- 示例图是 media-desk 的 still-life 样图，已 base64 内嵌，Canvas 不会被 file:// 污染。
- 设置抽屉里的 Key 输入、试连、保存都是演示交互，不发起网络请求。

## 设计取向

- **三栏**：风格库 / 印样台 / 参数；试印条在画布下方，结果和画布不分离。
- **视觉**：沿用 DSH 自建面板的暖纸 + 墨 + 单信号色；serif 标题、mono 元数据、发丝线分栏。
- **一个实心按钮**（生成），其余都是描边 / 安静按钮；云端费用在按钮上方显式提示。
- **风格卡是印刷色卡**，不是 App 图标；选中用红角标 + 墨线框，不做药丸。
- **画布是印样台**：裁切线、纸底、A/B 对比，而不是一个圆角图片框。
- **设置是抽屉，不是新页面**：改完关掉就回到工作台，不打断试印。

## 已知边界

- 重点做了 1120 宽度；1020 以下右栏落下，760 以下单栏。
- 上传只接受浏览器能解的图片；HEIC 在正式版应由 Host 转码。
- A/B 拖拽、设置里的按钮是演示级；正式插件已改成每张试印卡右上角「下载」，并去掉了「点对比原图看差异」提示。
